# GD3_NatureMorteUnity_JulieManceau
Devoir de nature morte sur Unity

La consigne demandait de réaliser une nature morte avec le style de notre PFE avec la présence d'éléments précis comme la texture métallique, transparente, masked et opaque non métallique.  

Comme l'esthétisme de mon PFE correspond à des illustrations vectorielles j'ai dû faire des compromis pour répondre le plus possible à la consigne.
Pour s'approcher de cet esthétisme, l'idéal aurait été de faire un Shader/MaterialFunction toon sur l'ensemble de la scène (avec en supplément les materials en Unlit)
Pour répondre aux demandes de la nature morte de cet exercice, je me suis alors approché le plus possible du style en utilisant un Shader/MaterialFunction mais en Lit, pour avoir le travail des ombres/lumières sur les objets. Les matériaux spécifiques demandés pour cet exercice n'ont pas d'aspect toon pour qu'on puisse voir les reflets.
Une outline est présente autour de la composition pour imiter les effets de lumière voulu pour certains éléments du jeu.

Le même ReadMe est présent sur le Projet nature morte d'Unreal.
